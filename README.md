One original line of fortune-cookie wisdom for a software developer, at most 120 characters.

**Entry:** "The estimate you give today will be quoted back to you as a promise tomorrow."

`main.py` (stdlib only) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), then verifies it: exactly one line, 77 characters, no trailing newline, sha256-checked.

Run it:

```sh
python3 main.py
```
